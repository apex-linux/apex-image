# Apex image: the curated GNOME 51 desktop (ARCHITECTURE 7.1, ADR 0007).
#
# Format: one binary package name per line; everything after '#' is a comment.
# Installed with weak dependencies OFF, so useful weak dependencies of GNOME
# (fonts, thumbnailers, gvfs back ends, portals, Bluetooth UI) are listed explicitly.
# GTK3 is allowed only through image/audit/legacy-allowlist.txt; image/checks/legacy.sh
# fails the build on any other GTK3 or X server consumer.
#
# Every name was checked against the Fedora 45 x86_64 repodata (development/45
# Everything plus updates-testing) on 2026-09-24. Until F45 GA, the GNOME 51.0 builds
# come from updates-testing through updates-testing-allowlist.txt.
