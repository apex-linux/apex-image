# Apex image: compose-time exclude guards (ADR 0007).
#
# Format: one binary package name per line (exact names, no globs: rpm-ostree matches
# exclude-packages by name); everything after '#' is a comment. image/Containerfile
# passes each line as `--exclude <name>` to build-rootfs (and as dnf5 excludepkgs in
# the COMPOSE=dnf fallback). An excluded package can then not enter the image by any
# path: if something we install hard-requires it, the depsolve fails loudly.
#
# RULE: never list a hard requirement (including a satisfied conditional
# requirement) of something we install. Such packages go into
# image/audit/legacy-allowlist.txt instead. Known cases on F45:
#   - gdm hard-requires xorg-x11-xinit, which requires setxkbmap, xhost, xmodmap,
#     xorg-x11-xauth and xrdb;
#   - gnome-session-wayland-session hard-requires xorg-x11-server-Xwayland;
#   - ibus requires `(ibus-gtk3 if gtk3)`, and gtk3 is present, so ibus-gtk3 is required;
#   - gnome-shell hard-requires xdg-desktop-portal-gtk and xdg-user-dirs-gtk.
# The list was checked with an approximate depsolve of base.txt + gnome.txt +
# apex.txt against the F45 repodata on 2026-09-24.
#
# Names that no longer exist in F45 (cheese, retired) are not listed: an exclude on a
# missing name guards nothing. image/checks/legacy.sh still bans them by name.
