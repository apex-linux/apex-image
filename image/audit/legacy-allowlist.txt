# Apex legacy allowlist (ADR 0007). Read by image/checks/legacy.sh.
#
# Format: one entry per line, three TAB-separated fields:
#   name<TAB>milestone<TAB>reason
# - name: an installed binary package that legacy.sh flags (it requires or provides
#   GTK3 or GTK2, requires or provides the Xorg server, belongs to the X11 session
#   userland, or is banned by name).
# - milestone: when the entry is expected to go away. A ROADMAP milestone (M1, M1.1,
#   M2, M3) when Apex work removes it, or F46 when removal depends on upstream or
#   Fedora and is re-checked at the Fedora 46 rebase at the latest.
# - reason: why it is here and what removes it.
# Lines starting with '#' and blank lines are ignored.
#
# This list may only shrink. legacy.sh prints a WARN line for entries that are no
# longer installed or no longer flagged; delete them in the next change.
#
# Verified 2026-09-24 against the F45 repodata (development/45 + the GNOME 51.0
# builds admitted from updates-testing) with an approximate depsolve of
# image/packages/{base,gnome,apex}.txt: these are exactly the GTK3 consumers and the
# X11 session userland it pulls in. Package names were checked in the same repodata.

# The GTK3 toolkit itself. Flagged as the provider of libgtk-3/libgdk-3 (its rpm header
# also lists them as requirements of its own binaries; createrepo drops those, which is
# why the depsolve above did not show it). It goes when the last consumer below goes.
gtk3	F46	The GTK3 toolkit, a hard dependency of every GTK3 consumer below (xdg-desktop-portal-gtk, ibus, evolution-data-server, ...). Removed with the last of them.

# GTK3 consumers of the GNOME 51 core and our app set
xdg-desktop-portal-gtk	F46	gnome-shell hard-requires it; still the only Inhibit and Email portal backend (xdg-desktop-portal-gnome 51 lacks both). Removed when GNOME drops the requirement or an Apex Rust portal backend replaces it.
xdg-user-dirs-gtk	F46	gnome-shell 51 hard-requires it (plain xdg-user-dirs would do). Removed when the Fedora spec drops the requirement.
evolution-data-server	F46	gnome-shell links libecal/libedataserver; Fedora builds the main package with GTK3 and webkit2gtk-4.1 OAuth2 support. No private fork (ADR 0007).
webkit2gtk4.1	F46	Hard dependency of evolution-data-server (OAuth2 WebKitGTK 4.1, GTK3). Goes with evolution-data-server.
libcanberra-gtk3	F46	Linked by evolution-data-server and gnome-disk-utility. Goes when both drop GTK3.
gnome-desktop3	F46	gnome-desktop4 hard-requires gnome-desktop3, which carries the GTK3 libgnome-desktop-3 (legacy_library=true upstream default).
gnome-autoar	F46	nautilus and gnome-shell link gnome-autoar 0.4.5, whose main package bundles the GTK3 libgnome-autoar-gtk; upstream 0.5.0 removed it, waiting for the Fedora rebase.
ibus	F46	GNOME Shell's input-method framework (m17n:vi:telex); the main package ships the GTK3 extension and the X11 helper. No private fork (ADR 0007).
ibus-gtk3	F46	ibus requires (ibus-gtk3 if gtk3) and gtk3 is present, so it cannot be excluded. Goes with ibus or with gtk3.
gnome-disk-utility	F46	GNOME Disks 46.1 is GTK3 + libhandy; allowlisted until the GTK4 port (51.beta upstream) ships in Fedora (ADR 0007).
libhandy	F46	Hard dependency of gnome-disk-utility 46 (GTK3). Goes with the GTK4 GNOME Disks.
gstreamer1-plugins-bad-free	F46	Its gtkwaylandsink element links GTK3; Snapshot hard-requires the package (and Decibels its -libs). Removed if Fedora splits the GTK3 element into a subpackage.
libdecor	F46	xorg-x11-server-Xwayland hard-requires libdecor, whose GTK plugin links GTK3. Xwayland itself is kept for X11 applications.
vte291	F46	Ptyxis uses vte291-gtk4, which hard-requires vte291 (shared files), and vte291 carries the GTK3 libvte. Removed if Fedora splits the common files.

# X11 session userland required by gdm (not the Xorg server)
xorg-x11-xinit	F46	gdm 51 in Fedora is built with %bcond x11 1 and hard-requires it (per-user X server for other desktops' X11 sessions). No Xorg server is installed.
setxkbmap	F46	Required by xorg-x11-xinit (gdm chain).
xhost	F46	Required by xorg-x11-xinit (gdm chain).
xmodmap	F46	Required by xorg-x11-xinit (gdm chain).
xorg-x11-xauth	F46	Required by xorg-x11-xinit (gdm chain).
xrdb	F46	Required by xorg-x11-xinit (gdm chain).
